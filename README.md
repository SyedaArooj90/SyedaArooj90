**[Crumbwell](https://github.com/SyedaArooj90/Crumbwell)**
A full-stack bakery website that I built end to end.
- Frontend: React with Vite and React Router. Menu with categories and search, cart, checkout, and an admin dashboard.
- Backend: Node and Express API with JWT login. Four roles (admin, owner, salesperson, customer) each see different things.
- Database: MongoDB, with the data model planned first through an ER diagram. It covers orders, bills, stock, suppliers, employees, salaries and more.
- Business side: orders and billing, stock and purchase orders, counter sales, and reports for profit and loss.
